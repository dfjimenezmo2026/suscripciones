SubsTrack - Mini app para Hostinger

Instalación:
1. Descomprime el ZIP.
2. Sube TODO el contenido de la carpeta SubsTrack_Hostinger a public_html o a una subcarpeta.
3. Abre index.html desde tu dominio.
4. Para que la PWA/offline funcione correctamente, usa HTTPS (Hostinger normalmente lo ofrece).

Características:
- Dashboard de gasto mensual/anual
- Suscripciones activas, pausadas, canceladas y pruebas gratis
- Próximos cobros y calendario
- Múltiples ciclos: semanal, mensual, trimestral y anual
- Método de pago, etiquetas, notas y renovación automática
- Nivel de uso para detectar suscripciones olvidadas
- Detector de aumentos de precio
- Simulador de ahorro
- Presupuesto mensual
- Estadísticas e historial de pagos
- Exportación CSV
- Backup/importación JSON
- Modo oscuro
- PWA y modo offline
- Datos guardados localmente en el navegador

No depende de páginas, marcas, PDFs ni recursos de terceros.
